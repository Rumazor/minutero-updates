# minutero-updates

Versiones publicadas de **Minutero**, la app de escritorio para Windows que graba, transcribe y
resume reuniones.

- `minutero.exe`: la última versión. Se puede descargar y abrir directamente; desde la propia app,
  «Instalar» la deja en el menú Inicio.
- `version.json`: qué versión es y su suma SHA-256. La app instalada lo consulta para actualizarse
  sola.

Aquí no está el código: solo el ejecutable.
